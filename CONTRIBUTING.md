# Contributing

The original repository for this project is [`DebarghaG/proofofthought`](https://github.com/DebarghaG/proofofthought). The ICICLE fork tracks its `main` branch.

- Submit changes to the project through [upstream pull requests](https://github.com/DebarghaG/proofofthought/pulls).
- Report bugs and request project features through [upstream issues](https://github.com/DebarghaG/proofofthought/issues).
- For changes to the ICICLE catalog metadata or the fork's CI and sync workflows, open a pull request in the [ICICLE fork](https://github.com/ICICLE-ai/proofofthought/pulls).
